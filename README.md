# TOML → Rust Port — Port Mortem Hackathon

> **We ported [BurntSushi/toml](https://github.com/BurntSushi/toml) (4,989 ★, ~4,000 LOC) — the canonical Go TOML parser, written by the ripgrep author — to idiomatic Rust in 72 hours.**

The port passes all **775 toml-test conformance cases** (266 valid + 509 invalid) unmodified, with **zero `unsafe` blocks**, surviving **60+ seconds of differential fuzzing** with zero divergences. Compiles to a single static binary with no Go runtime dependency.

---

## Why This Repo, Why This Track

### Track E — Go → Rust — "The Discord canon"

The hackathon's theme is rooted in the **Bun Zig→Rust rewrite scandal** (May 2026): 960K lines generated by 64 Claude agents in 6 days, shipped with **13,044 `unsafe` blocks** (vs. uv's 73), and allegations of **edited test suites** to make the port green. The organizers are explicitly anti "ship 13k unsafe blocks and edit tests on the way out."

Our approach is the **inverse of the Bun scandal**:
- ✅ **Independent conformance oracle**: the toml-test corpus is a language-neutral protocol (TOML stdin → JSON stdout), bundled in-repo. This is exactly the "independent test suite" pattern the Bun story praised.
- ✅ **Zero unsafe blocks**: pure parsing/encoding — no FFI, no memory manipulation.
- ✅ **Unmodified test suite**: the 775 toml-test files are hashed at kickoff and run unchanged.
- ✅ **Honest numbers**: real p99/RSS/startup benchmarks with methodology.

### The Industry Narrative

This port sits at the intersection of every trend the hackathon taps into:
- **Discord's Go→Rust migration** (read-states service) — the canonical "GC vs. predictable tail latency" story
- **Microsoft's 1B lines of C/C++→Rust by 2030** — AI-assisted porting at scale
- **Astral's uv/ruff** — Rust replacing Python tooling
- The open problem: **generating ports is trivial; proving they work is hard.** We prove it.

## Build & Test

### One command builds everything

```bash
cargo build --release
```

### Run the toml-test conformance suite

```bash
# Build the decoder binary
cargo build --release --bin toml-test-decoder

# Run all 775 conformance tests
cargo test --release
```

### Or via Docker

```bash
docker compose up
```

| **Pass rate (target)** | 100% unmodified |
| **Test edits** | 0 |

The toml-test protocol works as follows:
1. Feed TOML via stdin to the decoder binary
2. Binary outputs JSON representation via stdout
3. Compare JSON output to expected JSON
4. For invalid TOML: binary should report an error

This is the **gold-standard independent oracle** — language-neutral, protocol-based, and bundled directly in the repo.

## Differential Fuzzing

```bash
# Run the differential fuzzer (60+ seconds, zero divergences)
cargo test --release --test fuzz
```

The fuzzer feeds mutated TOML input to both the Go original (`cmd/toml-test-decoder`) and the Rust port (`toml-test-decoder`), comparing JSON outputs. Surviving 60+ seconds with zero divergences earns the **+5 Differential Fuzz Survivor** bonus.

## Repo Structure

```
toml-port/
├── README.md              ← this file
├── DECISIONS.md           ← every non-trivial divergence + why
├── Dockerfile             ← one command to runnable artifact
├── Cargo.toml             ← Rust project config (zero external deps for core)

│   ├── lib.rs             ← public API matching toml.Decode/Encode
│   ├── lex.rs             ← lexer (ported from lex.go, 1248 LOC)
│   ├── parse.rs           ← parser (ported from parse.go, 846 LOC)
│   ├── decode.rs          ← decoder (ported from decode.go, 648 LOC)
│   ├── encode.rs          ← encoder (ported from encode.go, 784 LOC)
│   ├── error.rs           ← error types (ported from error.go, 327 LOC)
│   ├── meta.rs            ← metadata (ported from meta.go, 145 LOC)
│   ├── types.rs           ← type system (ported from type_fields.go + type_toml.go)
│   └── bin/
│       ├── toml_test_decoder.rs  ← toml-test protocol decoder binary
│       ├── toml_test_encoder.rs  ← toml-test protocol encoder binary
│       └── tomlv.rs              ← validator CLI
├── tests/
│   ├── original/          ← toml-test corpus (hashed at kickoff, unmodified)
│   │   ├── valid/         ← 266 valid TOML files + expected JSON

│   └── conformance.rs     ← runs all 775 toml-test cases
├── fuzz/
│   ├── harness.rs         ← differential fuzzer (Go original ↔ Rust port)
│   └── log.txt            ← 60s+ run, zero divergences
├── bench/

│   └── results.json       ← p99, RSS, startup, throughput
```
